## Неизменяемый принцип

> **Приоритет источников данных: Папка → Файл → XML-мета**  
> Этот порядок не меняется ни при каких условиях ни для каких фаз получения значений авторов и серий.

## Фаза 0 — Классификация структуры папок

**Задача:** Определить тип каждой папки до начала извлечения данных.

**Инструмент:** Новый модуль `folder_classifier.py`. Использует существующие списки из `config.json` и два новых BL.

### Источники классификации из config.json

| Ключ в конфиге | Роль в классификации | Статус |
|----------------|---------------------|--------|
| `filename_blacklist` | Содержит издательские/жанровые слова (`"серия"`, `"боевая фантастика"`, `"ЛенИздат"`) → BL-Publisher | Уже есть |
| `collection_keywords` | Ключевые слова тематических сборников (`"сборник"`, `"антология"`, `"коллекция"`) → BL-Collection | Уже есть |
| `male_names` + `female_names` | ~700 имён — используются для **валидации** авторских папок: если слово в имени папки совпадает с известным именем → AUTHOR | Уже есть |
| `author_series_patterns_in_folders` | Паттерны форматов авторских папок (`"(Surname) (Name)"`, `"Author, Author"` и др.) → правила парсинга имени автора из папки | Уже есть |
| `author_name_patterns` | Форматы имён авторов — используются при нормализации извлечённого имени | Уже есть |
| `no_series_folder_names` | `"Вне серий"`, `"Без серии"` и др. → папка не является серией | Уже есть |
| `variant_folder_keywords` | `"вариант"`, `"ЛП"`, `"СИ"` и др. → папка является вариантом/изданием | Уже есть |

Два новых BL (добавить в config.json):

| BL | Назначение | Примеры значений |
|----|-----------|-----------------|
| `publisher_prefixes` | Точные префиксы издательских папок | `"Серия - «"`, `"Серия «"`, `"Серия - "` |
| `system_folder_names` | Технические папки — игнорировать | `"FB2"`, `"tmp"`, `"_backup"`, `"covers"` |

### Каскадная логика классификации (в порядке приоритета)

1. Имя папки в `system_folder_names` → **SKIP**
2. Имя папки начинается с `publisher_prefixes` → **PUBLISHER**
3. Имя папки содержит слово из `filename_blacklist` или `collection_keywords` → **PUBLISHER / COLLECTION**
4. Имя папки содержит слово из `variant_folder_keywords` → **VARIANT** (вариант/издание серии)
5. Имя папки содержит слово из `no_series_folder_names` → **NO_SERIES**
6. Имя папки содержит известное имя из `male_names` или `female_names` → **AUTHOR** (надёжная валидация)
7. Имя папки соответствует паттерну из `author_series_patterns_in_folders` (например `"(Surname) (Name)"`) → **AUTHOR**
8. Иначе → **UNKNOWN** (обработка только через файл и XML)

### Реальные примеры

```
"Серия - «Боевая фантастика»(ЛенИздат)"
    → шаг 2: publisher_prefixes "Серия - «" → PUBLISHER

"Сборник Попаданцы. Древняя Русь"
    → шаг 3: collection_keywords "сборник" → COLLECTION

"Волков Тим"
    → шаг 6: "Тим" в male_names → AUTHOR

"Абрахам Дэниел (Джеймс С.А. Кори)"
    → шаг 6: "Дэниел" в male_names → AUTHOR (псевдоним в скобках → отдельное поле)

"ISCARIOT"                           ← это подпапка серии внутри авторской папки, не топ-уровень
    → шаг 8: → UNKNOWN
    → но родительская папка "Волков Тим" уже AUTHOR → подпапка автоматически = серия (см. Фазу 2)

"FB2"
    → шаг 1: system_folder_names → SKIP
```

## Фаза 1 — Извлечение АВТОРА (Папка → Файл → XML)

### 1.1 Папка (только для AUTHOR-типа)

Имя папки L1 = кандидат на автора. Формат: `Фамилия Имя` → нормализованный вид.  
Псевдоним в скобках сохраняется отдельно.

```
"Волков Тим/"                        → proposed_author = "Волков Тим"
"Абрахам Дэниел (Джеймс С.А. Кори)" → proposed_author = "Абрахам Дэниел"
                                        pseudonym = "Джеймс С.А. Кори"
```

Для **PUBLISHER / COLLECTION / UNKNOWN** — автора из папки нет.

### 1.2 Файл (паттерны F1/F4 через compile_patterns())

Применяются конфиг-паттерны к имени файла.  
Для F2 / F3 / F5 — автора в имени файла нет, шаг пропускается.

```
"Авраменко Александр - Солдат удачи 1. Солдат удачи.fb2"  → "Авраменко Александр"
"Волков Тим - Дуэлянт (Тетралогия).fb2"                   → "Волков Тим"
```

### 1.3 XML `<author>` (проверка + нормализация + fallback)

- Автор из папки/файла **найден** → XML сравнивается и нормализует порядок слов через `author_name_patterns`:
  - Папка `"Волков Тим"` + XML `"Тим Волков"` → совпадение, нормализованный = `"Волков Тим"`
  - Папка `"Волков Тим"` + XML `"Коротков Сергей"` → **несовпадение**, сохранить оба (`folder_author` / `actual_author`)
- Автор **не найден** ни в папке, ни в файле → XML = единственный источник:
  - `"1. Пробуждение Левиафана.fb2"` в `Абрахам Дэниел/Пространство/` → XML: `"Джеймс Кори"` → `actual_author = "Джеймс Кори"`

### 1.4 Нормализация автора через author_surname_conversions

После получения автора из любого источника — применить маппинг из конфига:
```
"Горъ (Гозалишвили) Василий" → "Горъ Василий"
"Лейкин Марк"                → "Мах Макс"
"Юнас"                       → "Йонас"
```
Это гарантирует единообразие имён независимо от источника.

## Фаза 2 — Извлечение СЕРИИ (Папка → Файл → XML)

> Фаза 2 разблокируется знанием о типе папки из Фазы 0 и авторе из Фазы 1.

### 2.1 Папка (только для AUTHOR-типа, файл в подпапке L2)

Подпапка L2 = серия автоматически, без дополнительного анализа.

```
"Волков Тим/Дуэлянт/1. Кодекс дуэлянта.fb2"               → series = "Дуэлянт"
"Абрахам Дэниел/Пространство/0.1. Двигатель (рассказ).fb2" → series = "Пространство"
                                                              (даже если XML не содержит <sequence>)
"Абрахам Дэниел/Кинжал и Монета/2. Королевская кровь.fb2"  → series = "Кинжал и Монета"
```

Файл прямо в авторской папке (L1, без подпапки) — серии из папки нет, переход к 2.2:
```
"Волков Тим/Бездна.fb2"  → серии из папки нет → 2.2
```

### 2.2 Файл (конфиг-паттерны через compile_patterns())

Применяется для PUBLISHER / COLLECTION / UNKNOWN папок и для файлов на L1 авторской папки.

```
"Авраменко Александр - Солдат удачи 1. Солдат удачи.fb2"  → series = "Солдат удачи"
"Волков Тим - Дуэлянт (Тетралогия).fb2"                   → series = "Дуэлянт", is_compilation=True
"0.1. Двигатель (рассказ).fb2"                             → серии нет в имени → 2.3
```

### 2.3 XML `<sequence name>` (fallback)

```
"Волков Тим/Земля живых.fb2"
    папка не даёт серию (L1), файл F2 без серии →
    XML: sequence name="Антология фантастики" → series = "Антология фантастики"
```

## Фаза 3 — Извлечение НОМЕРА (Файл → XML)

> Папка номер не содержит. Приоритет начинается с файла.

### 3.1 Прямой номер из имени файла (F3 / F5)

```
"1. Путь Дракона.fb2"           → number = "1"
"0.1. Двигатель (рассказ).fb2"  → number = "0.1"  (дробный → флаг short_story)
```

### 3.2 Номер внутри имени файла F1-variant

```
"Авраменко Александр - Солдат удачи 1. Солдат удачи.fb2"  → number = "1"
```

### 3.3 Диапазонный номер F4 (компиляция)

Словарь типов серий хранится в `config.json`.

```
"Волков Тим - Дуэлянт (Тетралогия).fb2"            → range = "1-4",  is_compilation = True
"Абрахам Дэниел - Пространство (т. 0-9).fb2"        → range = "0-9",  is_compilation = True
"Волков Тим - Земский докторъ (Окталогия).fb2"      → range = "1-8",  is_compilation = True
```

Словарь типов:

| Слово | Размер |
|-------|--------|
| Дилогия | 2 |
| Трилогия | 3 |
| Тетралогия | 4 |
| Пенталогия | 5 |
| Окталогия | 8 |
| т. X-Y | парсится как диапазон |

### 3.4 XML `<sequence number>` (fallback)

Только если номер не найден в файле.

## Фаза 4 — Pass 4: Консенсус и нормализация

Логика Pass 4 остаётся близкой к текущей с уточнениями:

- Консенсус по серии — только внутри одной группы `(folder_path, author)`
- Subseries валидация (реализована): минимум 2 файла подтверждают подсерию
- Trailing number strip (реализован)
- Re-fix series_number из стема (реализован)
- **Новое:** если `actual_author ≠ folder_author` → файл не участвует в авторском консенсусе

## Фаза 5 — Компилятор: группировка и дедупликация

### 5.1 Ключ группы

`(normalized_series, normalized_author)` — без изменений.

### 5.2 F4-файлы = precompiled

Любой файл с `is_compilation=True` и `range=lo-hi` → добавляется в `precompiled` список группы.  
Отдельные тома, чей номер попадает в диапазон → помечаются как дубликаты.

```
Группа "Дуэлянт / Волков Тим":
  precompiled: "Волков Тим - Дуэлянт (Тетралогия).fb2"  [range 1-4]
  duplicates:  "1. Кодекс дуэлянта.fb2", "2...fb2", "3...fb2", "4...fb2"
```

### 5.3 Предупреждение о пересечении диапазонов (реализовано)

Две компиляции с пересекающимися ranges → оранжевый highlight в GUI.

## Паттерны имён файлов (справочник)

| Код | Паттерн | Доля | Пример |
|-----|---------|------|--------|
| F1 | `[Author] - [Title]` | ~48.9% | `Авраменко Александр - Падальщик.fb2` |
| F2 | `[Title Only]` | ~23.2% | `Честь негодяев.fb2` |
| F3 | `[N]. [Title]` | ~14.2% | `1. Путь Дракона.fb2` |
| F4 | `[Author] - [Series] ([Type])` | ~13.6% | `Волков Тим - Дуэлянт (Тетралогия).fb2` |
| F5 | `[X.Y]. [Title] ([Type])` | ~0.1% | `0.1. Двигатель (рассказ).fb2` |

## Типы папок (справочник)

| Тип | Признак | Пример |
|-----|---------|--------|
| AUTHOR | regex `Фамилия Имя` | `Волков Тим/` |
| PUBLISHER | BL-Publisher prefix | `Серия - «Боевая фантастика»/` |
| COLLECTION | BL-Collection keyword | `Сборник Попаданцы. Древняя Русь/` |
| SKIP | BL-SystemFolders | `FB2/`, `tmp/` |
| UNKNOWN | ни под что не попало | `ISCARIOT/` |
