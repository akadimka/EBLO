## Проблемные зоны

### 1. `filename` — 1 009 записей, ~62% несовпадений с метой

Серия извлечена из имени файла без подтверждения метаданными. Наиболее ненадёжная категория.

Примеры ошибок:
- `Тарханов Влад - Цена империи 3. Фактор нестабильности.fb2`
  → proposed: `Цена империи`, metadata: `Михайловичи` (полностью разные серии)
- `Теслёнок Кирилл. Протокол Новый Архимаг 1-5.fb2`
  → proposed: `Протокол Новый Архимаг`, metadata: `Новый Архимаг` (лишние слова)
- `Март Артём - Пограничник 7. Призраки Пянджа.fb2`
  → proposed: `Пограничник`, metadata: `Пограничник [Артём Март]` (суффикс автора отброшен)

**Вопрос**: стоит ли понизить приоритет `filename`-источника или требовать подтверждение метой?

### 2. `folder_hierarchy` — 2 521 запись, ~28% несовпадений

Папки называются не так, как официальное название серии.

Примеры:
- Папка `Идеальный мир для Социопата` → metadata: `Социопат`
- Папка `Темная Империя` → metadata: `Королевство`
- Папка `Второй шанс` → metadata: `Никто кроме нас (Шабловский)`

### 3. `author-consensus` — 83 записи, ~33% несовпадений

Принцип "все книги одного автора = серия" ненадёжен.

Примеры:
- `Алексеев Михаил - Неожиданный шанс.fb2`
  → proposed: `Неожиданный шанс` (название книги как серия), metadata: `Попаданец (АСТ)`
- `Таунсенд Сью - Адриан Моул. Годы прострации.fb2`
  → proposed: `Адриан Моул`, metadata: `Дневники Адриана Моула`

### 4. Пустые серии (2 735 записей)

- 551 запись имеет metadata_series, но серия не была присвоена — упущенные возможности
- Часть папок содержит явные указания на серию, но extraction не сработал
